1　数据来源与任务

选用 Stanford Network Analysis Project（SNAP）发布的 CA-HepTh 合作网络。数据来自 arXiv 高能物理理论类别，覆盖 1993 年 1 月至 2003 年 4 月。作者为节点，两位作者共同署名至少一篇论文就形成合作关系。边表为制表符分隔的两列整数 FromNodeId、ToNodeId，仅含匿名作者编号。

实验用 PageRank 排序合作网络中的作者，再用节点向量检索结构相近的作者。合作关系按无权边处理，因为所用边表没有提供共同署名次数。

2　清洗与图模型

跳过注释，保留原始端点中的所有作者。删除 25 条自环，将每对作者映射为 (min(u,v), max(u,v)) 后去重。数据库只存一条 COAUTHOR 边，算法构造邻接矩阵时为每条边补上反向项。

PageRank 作者中心性

4　算法原理与参数

将作者视为均匀选择合作者进行跳转的随机游走者。对有合作者的作者 i，转移概率 P(i,j)=A(i,j)/d(i)。孤立节点的概率质量均匀分给所有节点。阻尼系数为 0.85，从均匀分布开始迭代。

r′ = 0.85 × (Pᵀr + 孤立节点概率质量 / n) + 0.15 / n
transition = diags(inv) @ adjacency
for iterations in range(1, 1001):
    updated = .85 * (transition.T @ rank + rank[dangling].sum()/n) + .15/n
    residual = np.abs(rank - updated).sum()
    rank = updated
    if residual < 1e-12:
        break

实测结果

第 140 轮达到停止阈值，末次 L1 变化量为 9.724e-13，分数之和为 1.000000000000。图中有 429 个连通分量，最大分量有 8,638 个节点。

谱矩阵分解节点嵌入

5　算法原理与参数

对称归一化邻接矩阵 S=D⁻¹ᐟ²AD⁻¹ᐟ²，孤立点的归一化系数置零。构造 C=S+S²，将直接合作和两步共同邻居纳入结构表示。用随机化截断 SVD 计算 32 个奇异分量，以左奇异向量各列乘相应奇异值的平方根，取得节点向量。

scale = diags(np.sqrt(inv))
normalized = scale @ adjacency @ scale
context = normalized + normalized @ normalized
left, sigma, _ = randomized_svd(context, n_components=32,
                                n_iter=10, random_state=42)
embedding = left * np.sqrt(sigma)

实测结果

向量矩阵尺寸 9,877 × 32，其中 2 个节点的向量范数为零。零向量参与统计时相似度按 0 处理。比较全部 25,973 个合作对与等量均匀抽样的唯一非合作对（种子 42）。两类平均余弦相似度分别为 0.9684 和 0.3648，排序 AUC 为 0.9749。正例参与了嵌入构造，该指标衡量原图内区分度。

留出边验证与基线对比

6　验证方法

对数据库导出的无向边使用种子 42、43、44 独立划分。每次将 5,194 条真实合作边从图中移除，保留 20,779 条训练边。所有作者均保留。测试负例从完整图的非边中均匀抽取，排除自环并去重，共 5,194 对。每轮所有方法共用同一批测试样本。

归一化矩阵、共同邻居及 Jaccard 都只基于训练图。Jaccard 是两个邻居集合的交集大小除以并集大小，并集为空时记为 0。节点嵌入用余弦相似度评分，含零向量的样本记为 0。

基线和维度对比

ROC AUC 衡量正例排在负例之前的能力，同分计半。AP（平均精确率）侧重排序靠前的预测。表中报告三次实验的均值与样本标准差。

结果解释与复现

7　结果解释

作者 1441 的 PageRank 最高。排名与合作作者数存在差异，因为每位作者向各合作者传递的贡献被自身度数平分。报告只用匿名 ID 描述图中的位置。

原图内 AUC 为 0.9749，该分数包含用于构造嵌入的已知合作边。32 维嵌入在留出实验中的平均 AUC 为 0.8534。两者衡量不同问题，留出实验更适合评价未参与训练的合作关系。

原始边表没有合作时间、论文数或研究主题。随机留出验证衡量同一图上的边恢复，不能推断未来合作。评估用等量正负例，AP 以该抽样比例为条件。更换负样本比例或使用更难区分的负例会改变评估结果。
